# Unity project: 86-task scheduling environment

Open this directory in Unity Hub with Unity `6000.0.46f1`.

The only supported scene is:

`Assets/ML-Agents/Examples/PyramidsChange/Scenes/86.unity`

The local ML-Agents packages are intentionally referenced as sibling folders:

- `../../com.unity.ml-agents`
- `../../com.unity.ml-agents.extensions`

Do not move this project out of the release-root directory unless the relative
paths in `Packages/manifest.json` are updated accordingly.
